## Learning Philosophy

I try to follow several principles throughout this journey:

- **Understand before coding** — understand what a concept is and why it is needed before using it.
- **Learn by implementation** — write the code myself instead of only reading solutions.
- **Learn from mistakes** — record bugs, misunderstandings, and important corrections.
- **Review regularly** — reproduce previously solved problems without looking at the solution.
- **Connect theory with practice** — relate mathematical and machine learning concepts to actual implementations.
